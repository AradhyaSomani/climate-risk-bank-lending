# ESA WorldCover

- **Source:** ESA WorldCover 10 m 2021 v200, AWS open data bucket `esa-worldcover` (3x3 degree tiles).
- **Licence:** CC BY 4.0, attribution "(c) ESA WorldCover project / Contains modified Copernicus Sentinel data (2021) processed by ESA WorldCover consortium".
- **Classes used:** built-up (50) and cropland (40).
- **Used for:** flooded share of built-up and cropland area (Phase 1E) and susceptibility features (Phase 2B-C). One map year is applied to all events, which is a known simplification.
